# Webhook 调试台（本地）

同时对接多家支付渠道 / 物流平台回调时的本地调试工具。服务端负责**收、验、存、转发**，
浏览器实时查看每个回调的原始方法/路径/头/正文、服务端的验签结论，并支持按当前规则
脱敏后重放到本地目标地址。

技术栈：TypeScript · React 19 · Express 5 · Vite · Vitest + supertest。

## 快速开始

```bash
npm install
npm run dev      # 同时起 API(4174) 和 Vite 开发服务器(4173，已代理 /api、/hook)
```

浏览器打开 http://127.0.0.1:4173 。

生产方式（构建后由 Express 直接托管前端）：

```bash
npm run build
npm start        # http://127.0.0.1:4174
```

数据默认落在 `data/webhook.json`（已在 `.gitignore`，内含 HMAC 密钥，勿提交）。
可用 `WEBHOOK_DB=/path/to/db.json npm start` 改位置。

## 工作流

1. **来源页**登记来源，例如 `pay`。回调打到 `http://127.0.0.1:4174/hook/pay/` 下的任意路径、
   任意方法；可配置本地重放目标（如 `http://127.0.0.1:8080/callback`）。
2. **签名**：每个来源单独配 HMAC（sha1/sha256/sha512，hex/base64）、签名头名、
   时间戳头与允许偏差。换密钥期间可同时挂多把密钥，**新旧都认**，验签结果会标出命中哪一把。
   密钥只存本机文件，任何接口都不回显；编辑时密钥留空表示沿用已存值。
3. **规则页**配置脱敏规则，并可贴一段样例请求当场看处理前后对比。
4. **事件页**实时查看回调；勾选一条或多条重放。重放按**当前最新规则**重新处理后再发出。

## 验签：对原始字节

服务端不经过 body-parser 读取 `/hook`，而是自己按字节读取后直接验签，再解析。
因此只要对方发出的字节没被改动，中文写成 `\u` 转义、键顺序不同、JSON 里多空格都判通过；
验完之后再 `JSON.parse` 用于结构化展示。支持 `sha256=<digest>` 这种前缀风格。

时间戳支持 Unix 秒、Unix 毫秒或 ISO 8601。前端只展示服务端给的结论，结论分为：

| status | 含义 |
| --- | --- |
| `not-configured` | 该来源没配签名 |
| `unsigned-request` | 请求没带签名头（或为空） |
| `timestamp-out-of-range` | 时间戳头缺失 / 无法解析 / 超出允许窗口 |
| `malformed-signature` | 签名值不是合法的 hex/base64 |
| `mismatch` | 用所有已登记密钥重算都对不上 |
| `valid` | 通过，并给出命中的密钥 |

## 脱敏规则

- 作用对象：**请求头名**（大小写不敏感）或 **JSON 路径**。
- 处理方式：整项删除 / 换成固定文本 / 只留末尾几位（自定义遮盖字符）。
- JSON 路径为自实现的精简语法：`$.a.b`、`$["带.点的键"]`、`$[12]`、`$["x"][0]`。
  不支持通配符/递归/脚本/切片；路径写错会报「第 N 个字符」的具体位置。
- 规则同时作用于：**落盘文件、所有接口响应、SSE 推送帧、重放发出的内容**，
  以及重放时按当前规则重新处理的旧事件。
- `application/json`、`application/x-www-form-urlencoded`、`multipart/form-data` 的字段
  都按结构化数据处理；其它类型按纯文本逐字保存。

> 边界：JSON 路径规则只能命中能被成功解析的结构化正文。若对端声明 `application/json`
> 但发的字节并非合法 JSON，正文会按纯文本原样保存，路径规则无法定位其中字段——
> 需要隐藏此类内容时请用「请求头」规则，或让对端修正报文。规则作用域只有
> 「头名」和「JSON 路径」，不对任意文本做模糊匹配，以免误改非敏感内容。

## 实时与断线补漏

SSE 每帧带事件 `id`；连接 URL 带 `?after=<当前最大事件id>`，服务端在建连时补发期间错过的事件。
前端按 id 去重、按 id 排序，因此合盖 / 断网期间的回调在恢复后会补齐，**不重复、不乱序**。

## 其他行为

- 单个请求正文 **> 1MB 返回 413**，不解析、不验签、不留任何记录（恰好 1MB 通过）。
- 事件只保留最近 **500** 条；服务重启后事件、来源、规则、重放记录都在。
- 批量重放每条独立结算：目标返回的状态码、耗时、失败原因挂回原事件；一条失败不影响其它条。

## 测试

```bash
npm test          # Vitest + supertest，含一个测试内临时起的本地假目标服务
npm run build     # tsc --noEmit + vite build
```

覆盖：原始字节验签（转义/键序/空格、多密钥轮换、六种结论、密钥不回显）、
413 不落记录、JSON 路径解析与字符级报错、三种脱敏动作与原值零泄漏、
重放按新规则、部分失败互不影响、500 条上限、重启持久化、断线补拉。
